# English Learning App — Project Context

⚠️ **АРХИВ**: Этот документ описывает изначальную архитектуру с БД и адаптацией текстов через Claude API. 
Текущая реализация намного проще — см. [`AGENTS.md`](AGENTS.md) и [`CLAUDE.md`](CLAUDE.md) для актуальной информации.

---

## Идея продукта (исходная планировка)
Сервис для изучения английского через чтение. Пользователь выбирает книгу и свой уровень языка (A1–C1). Сервис адаптирует текст под уровень через AI. При клике на слово — перевод. Личный словарь из нажатых слов.

## Технический стек (исходный план)
- Backend: Node.js
- Frontend: React
- DB: PostgreSQL
- AI: Claude API (для адаптации текстов)
- Перевод слов: DeepL API

**Текущая реализация** (см. AGENTS.md):
- Backend: Node.js + Express 5 (БД нет, файловая система)
- Frontend: React + Vite
- Перевод: DeepL API (для перевода слов по клику)

---

## Исходная архитектура контента (более не используется)

Первоначально планировалась архитектура с двумя типами контента:
- **library** — готовые адаптированные книги
- **user_content** — онлайн адаптация пользовательского текста через Claude API

Для этого создавались 5 промптов разных уровней сложности (A1–C1), которые переписывали текст с разными правилами грамматики и словаря.

**Текущее состояние**: Все файлы хранятся как `.txt` в `library/{LEVEL}/{Автор}/{Книга}/` без адаптации. Это намного проще и эффективнее. Уровни сложности определяются самой структурой папок, а не адаптацией текста.
